## 10Mbps 不限流量到底能跑多少

不限流量听起来没有上限，实际上限被端口写死了。10Mbps 换算成下载速度是 1.25MB/s，持续跑满，一小时 4.5GB，一天约 108GB，30 天约 **3.2TB**。如果站点只是白天有访问、夜里空闲，实际月流量更接近 1.5TB 上下。

把这个数字放到同价位里对比就有意思了。人民币百元级的香港年付档，常见做法是"大端口 + 定额流量"：有商家 ￥88/年给 100Mbps 峰值配 380GB 月流量，也有 ￥150/年给 30Mbps 配 500GB 月流量。LightLayer 反过来，端口只给 10Mbps，但流量不设上限。

两种设计对应两种风险。定额流量的档位，端口大、下载快，但流量用穿了会被限速到 1Mbps 这种几乎不可用的状态，得盯着统计图过日子；不限流量的档位，跑多少都不心疼，但你永远不会比 1.25MB/s 更快。

所以判断标准很直接：**日均流量在 30GB 以内、没有大文件下载需求 → 10Mbps 不限流量这档更省心；需要经常传大文件、跑图床、做软件分发 → 别买香港这档，去看洛杉矶的 100Mbps 或 200Mbps，同价。**

## Premium、Standard、Global 三条线路怎么选

LightLayer 用 Premium、Standard、Global 给线路上档次，这套分法跟行业里常见的"普通 BGP / 优质 BGP / 精品 BGP"是同一个思路：普通线路接入多家国际带宽，谁便宜走谁；优质线路在内地回程上做优化，电信、联通、移动分别挑更顺的路由；精品线路则强制三网走指定的直连方向，价格最贵、体验最稳。

对应到 LightLayer 的命名，Premium 是对中国大陆方向优化最好的一档，Standard 居中，Global 走国际带宽、端口给得最大。同样 $24.99，香港只有 Premium（10Mbps），洛杉矶 Premium 给到 20Mbps、Standard 到 50Mbps、Global 到 100Mbps 甚至 200Mbps。

香港到内地的物理距离摆在那里，10Mbps 的 Premium 线路对国内访问的实际体验，通常好过洛杉矶 100Mbps 的 Global。带宽数字大不等于打开快，跨太平洋的往返延迟是绕不过去的。做面向国内用户的站，香港 10Mbps 是这批里最合适的选择；做面向海外用户的站，或者纯粹要大带宽下东西，洛杉矶 Global 才划算。

**不限流量会不会被限速？** 端口本身就是 10Mbps，谈不上额外限速，你能拿到的上限就是 1.25MB/s。
